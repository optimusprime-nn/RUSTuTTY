For Windows · Free and open source

All your terminal sessions in one window.

RUSTuTTY is PuTTY rewritten in Rust: the same settings, the same saved sessions and the same tools, with every session in one window, listed down the left.

Download Get started

Beta · 64-bit Windows 10 and 11 · Installs per user, no administrator rights needed

One window, every session

Open sessions sit in a list on the left. Switch with a click or Ctrl+Tab, and paste into all of them at once.

Your PuTTY sessions, untouched

It reads the sessions and host keys PuTTY saved, and never changes them. PuTTY carries on exactly as before.

Every PuTTY setting

The settings window has PuTTY's pages in PuTTY's order. If you know where a setting is in PuTTY, it's in the same place.

Dark and light

A modern look in dark or light, with a settings window you can resize, and the window size kept between runs.

The tools too

Plink, PSCP, PSFTP, PuTTYgen and Pageant, with the same names and options, so your scripts keep working.

Follows PuTTY

PuTTY's main branch is checked every day, and its fixes and features are ported across.

Everything you connect with

  • SSH-2, Telnet, Rlogin, SUPDUP, raw and serial
  • Passwords, keys, certificates, Pageant and authentication plugins
  • Local, remote and dynamic port forwarding, and X11
  • SOCKS, HTTP, telnet, command and SSH proxies
  • .ppk keys, versions 2 and 3, and OpenSSH keys
  • Logging, keepalives, environment variables, colours and fonts

What's different from PuTTY

Start in a minute

  1. Download the installer or the portable zip.
  2. Type user@host at the top left and press Enter.
  3. Or double-click a session you saved in PuTTY.
